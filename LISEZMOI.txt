PRONOS + SCORE EN DIRECT - BCV 43
=================================
Un seul site, un seul Firebase (le même que tes pronos). Rien à recréer.

1. FIREBASE (obligatoire, 1 minute)
   Firestore Database > Règles : remplace tout par le contenu de firestore.rules, puis Publier.
   (Nouveauté : une section "lives" pour le score en direct.)

2. GITHUB
   Dépôt > Add file > Upload files : envoie index.html, live.html, firebase-config.js, logo.png
   (remplace les anciens). Attends 1-2 minutes.

3. UTILISATION
   - Les joueurs se connectent comme avant (prénom + nom), ouvrent une rencontre puis un match.
   - Sous le bloc de paris, "Scorer ce match" : le premier qui lance le comptage devient le scoreur
     (il reprend la main s'il recharge la page ou change de téléphone avec son compte).
   - Les autres voient "Suivre le direct" : score en temps réel, stats, réactions, commentaires.
   - Dans la liste des matchs, un badge "En direct 21-15 8-6" apparaît.
   - Bouton "Parier" dans le direct = retour au match dans l'appli de paris (fermé après l'heure de début).
   - ADMIN : "Saisir les résultats" montre le résultat du live avec "Valider ce résultat" (un clic),
     puis "Calculer les points". "Réinitialiser le direct" annule un comptage lancé par erreur.

4. INTERCLUB OU TOURNOI (admin > Rencontres > Nouvelle rencontre)
   - Interclub : deux clubs ; n° d'équipe, compétition et journée sont facultatifs.
   - Tournoi : un nom de tournoi + date/heure, puis des matchs joueur contre joueur (cartes joueur).
   Seuls index.html et live.html changent ; les règles Firebase restent les mêmes.
